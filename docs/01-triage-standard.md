# L1 Triage Standard

## Investigation sequence
1. Identify alert, timestamp, host, user, source and destination.
2. Validate whether the activity is expected.
3. Collect related logs and context.
4. Correlate events into a timeline.
5. Decide True Positive, False Positive or Suspicious.
6. Assign severity using confidence, impact and urgency.
7. Close, monitor or escalate with evidence.
8. Record a concise analyst handoff.

## Minimum case output
Every completed case should contain an alert summary, evidence, timeline, verdict, severity, action and rationale.
